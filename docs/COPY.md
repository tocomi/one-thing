# マイクロコピー

## 基本方針

- **言語**: 日本語メイン。日付・技術的ラベルは英語
- **口調**: 語りかける口語。友人に話しかけるような自然な温度感
- **姿勢**: 称えるが押しつけない。静かに、じんわり染み込む言葉

---

## メイン画面

### 未設定状態 — 促すメッセージ（時間帯で切り替え）

| 時間帯 | メッセージ |
|--------|-----------|
| 〜12:00 | 「今日は何をする？」 |
| 12:00〜 | 「今日のひとつ、決めた？」 |

### 入力フィールド

| 要素 | コピー |
|------|--------|
| プレースホルダー | なし（空白のまま） |
| 確定ボタン | 「決めた！」 |

### 進行中状態

| 要素 | コピー |
|------|--------|
| 完了ボタン | 「できた！」 |
| ストリーク（n日以上連続） | 「{n}日連続達成中」 |

---

## 完了メッセージ（3〜5種ローテーション）

静かに称えるトーン。毎回ランダムで表示。

1. 「よくやった。」
2. 「それだけで、十分。」
3. 「今日も前に進んだ。」
4. 「ひとつ、できた。」
5. 「今日の自分を、ちゃんと褒めて。」

---

## 未達成メッセージ（3〜5種ローテーション）

今日を受け止めて、明日を否定しない。完了メッセージと同じ温度感。

1. 「今日は休んだ。それでもいい。」
2. 「できない日もある。また明日。」
3. 「休むのも、ちゃんと意味がある。」
4. 「今日はここまで。次の今日がある。」
5. 「無理しなかった。それでいい。」

---

## 通知

| 種類 | 文言 |
|------|------|
| 朝（未設定時） | 「おはよう。今日は何をする？」 |
| 夜（未完了時） | 「おつかれ。今日のひとつ、どうだった？」 |

> 完了済みの場合、夜の通知は送らない。

---

## 履歴・カレンダー

| 要素 | コピー |
|------|--------|
| シートタイトル | 「これまで」 |
| 達成日ラベル | なし（色で表現） |
| 未達成日ラベル | なし（色で表現） |
| 詳細の結果（達成） | 「できた」 |
| 詳細の結果（未達成） | 「休んだ」 |
| 詳細の結果（未記録） | 「記録なし」 |

> 「できなかった」ではなく「休んだ」と表現することで、責めないトーンを保つ。

---

## 設定

| 要素 | コピー |
|------|--------|
| シートタイトル | 「設定」 |
| 通知セクション | 「通知」 |
| 通知 ON/OFF | 「通知を受け取る」 |
| 朝の通知時間 | 「朝の通知」 |
| 夜の通知時間 | 「夜の通知」 |

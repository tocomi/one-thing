# 開発ルール

## Linear 連携ルール（エージェント向け）

エージェント（Codex / Claude Code）が実装タスクに取り組む際は、以下のルールに従って Linear を操作する。

---

### イシューの特定

- 作業内容のタイトル・説明をもとに Linear を検索し、対応するイシューを自分で特定する。
- 対応するイシューが見つからない場合は、**作業を開始せずユーザーに確認を求める**。

---

### ステータスフロー

```
Backlog / Todo
    ↓ 着手時（エージェントが変更）
In Progress
    ↓ 実装完了後（エージェントが変更）
In Review
    ↓ レビュー・コミット後（人間のみが変更）
Done
```

- エージェントはコミットを作成しない。実装完了後、作業内容をコメントして `In Review` に変更する。
- コミット作成と `Done` への変更は**人間のみ**が行う。エージェントは `In Review` 止まり。

---

### ラベル

| エージェント | ラベル |
|------------|--------|
| Claude Code | `claude-code` |
| Codex | `codex` |

- **着手時にラベルを付ける。**
- ラベルは完了後も外さず、そのまま残す（履歴として保持）。
- 複数のエージェントが同一イシューを触った場合は、両方のラベルを付ける。

---

### コメント

ステータス変更時に必ずコメントを投稿する。フォーマットは以下の通り。

**着手時（In Progress へ変更するとき）:**
```
🤖 [エージェント名]: 実装開始
```

**In Review へ変更するとき:**
```
🤖 [エージェント名]: 実装完了
```

例:
```
🤖 claude-code: 実装開始
🤖 claude-code: 実装完了
```

---

### アサイン

- エージェントはイシューのアサインを変更しない。ラベルとステータスで管理する。

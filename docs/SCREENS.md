# 画面仕様

## ナビゲーション構造

タブバーなし。メイン画面を主役に、サブ画面はすべてシート（モーダル）で表示する。

```
メイン画面
├── [カレンダーアイコン] → 履歴シート
└── [歯車アイコン]       → 設定シート
```

---

## メイン画面

ヘッダー右上にカレンダーアイコン、左上に歯車アイコンを配置。  
中央エリアが4つの状態によって切り替わる。

### 状態1: 未設定

朝、まだ今日のことを決めていない状態。

| 要素 | 内容 |
|------|------|
| 日付 | 今日の日付（例: May 5, Monday） |
| メッセージ | 「今日のひとつは？」などの入力を促す一言 |
| 入力フィールド | インライン入力。タップしてそのまま入力できる |
| 確定ボタン | 入力後に表示。タップで「進行中」状態へ遷移 |

### 状態2: 進行中

今日のことを決めた後、取り組んでいる状態。

| 要素 | 内容 |
|------|------|
| 日付 | 今日の日付 |
| 今日のこと | 決めたテキストを大きく表示。タップで編集可能 |
| 完了ボタン | 「できた」を記録する。タップで「完了」状態へ遷移 |
| ストリーク | 連続達成日数（例: 3日連続達成中）。達成中のみ表示 |

### 状態3: 完了

「できた！」を記録した後の状態。

| 要素 | 内容 |
|------|------|
| お祝い演出 | 完了記録時にアニメーションを表示 |
| 肯定メッセージ | 称える一言（例: 「今日もよくやった」） |
| 今日のこと | 完了したテキストを表示 |
| ストリーク | 更新された連続達成日数 |

完了記録のアニメーション後、この画面に落ち着く。翌朝になると自動でリセット。

### 状態4: 未達成

何も記録しないまま翌朝を迎えると自動的にこの状態になる。  
完了状態と同じ画面構造・温度感。メッセージのみ異なる。

| 要素 | 内容 |
|------|------|
| メッセージ | 受け止める一言（例: 「今日は休んだ。それでもいい。」） |
| 今日のこと | 設定していたテキストを表示 |

---

## 履歴シート

メイン画面のカレンダーアイコンから開く。

| 要素 | 内容 |
|------|------|
| 月カレンダー | 達成・未達成・未記録を色で区別 |
| 日付選択 | タップするとその日の詳細を表示 |
| 日次詳細 | 選んだ日のことと結果を表示。過去の記録は編集可能 |

### カレンダーの色定義

| 状態 | 表示 |
|------|------|
| 達成 | 塗りつぶし（黒） |
| 未達成 | アウトラインのみ |
| 未記録（未来・設定なし） | 何も表示しない |

---

## 設定シート

メイン画面の歯車アイコンから開く。

| 設定項目 | 内容 |
|----------|------|
| 通知 ON/OFF | 朝・夜の通知をまとめて切り替え |
| 朝の通知時間 | 「今日のひとつを決めよう」を送る時刻（デフォルト: 8:00） |
| 夜の通知時間 | 「今日のひとつ、どうだった？」を送る時刻（デフォルト: 21:00） |

---

## 画面遷移サマリー

```
起動
└── メイン（未設定）
    └── 入力・確定
        └── メイン（進行中）
            ├── 完了ボタン → メイン（完了）
            └── 翌朝リセット → メイン（未達成 or 未設定）

メイン（任意の状態）
├── カレンダーアイコン → 履歴シート
│   └── 日付タップ → 日次詳細（編集可）
└── 歯車アイコン → 設定シート
```

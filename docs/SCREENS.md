# 画面仕様

## ナビゲーション構造

タブバーなし。メイン画面を主役に、サブ画面はすべてシート（モーダル）で表示する。

```
メイン画面
├── [カレンダーアイコン] → 履歴シート
└── [歯車アイコン]       → 設定シート
```

---

## メイン画面

ヘッダー右上にカレンダーアイコン、左上に歯車アイコンを配置。  
中央エリアが3つの状態によって切り替わる。

### 状態1: 未設定

朝、まだ今日のことを決めていない状態。

| 要素 | 内容 |
|------|------|
| 日付 | 今日の日付（例: 5月5日（月）） |
| メッセージ | 「今日は何をする？」などの入力を促す一言 |
| 入力フィールド | インライン入力。タップしてそのまま入力できる |
| 確定ボタン | 入力後に表示。タップで「進行中」状態へ遷移 |

### 状態2: 進行中

今日のことを決めた後、取り組んでいる状態。

| 要素 | 内容 |
|------|------|
| 日付 | 今日の日付 |
| 今日のこと | 決めたテキストを大きく表示。タップで編集可能 |
| 完了ボタン | 「できた」を記録する。タップで「完了」状態へ遷移 |

当日中に「休んだ」を記録する操作はメイン画面には置かない。  
完了しないまま日付の区切り時刻を過ぎた場合、自動的に履歴へ「休んだ」と記録する。

### 状態3: 完了

「できた！」を記録した後の状態。

| 要素 | 内容 |
|------|------|
| お祝い演出 | 完了記録時にアニメーションを表示 |
| 肯定メッセージ | 称える一言（例: 「今日もよくやった」） |
| 今日のこと | 完了したテキストを表示 |

完了記録のアニメーション後、この画面に落ち着く。翌朝になると自動でリセット。

完了後はメイン画面から今日のことを編集できない。必要な場合は履歴から編集する。

### 日付の切り替わり

1日の区切り時刻はデフォルト AM4:00。設定から変更できる。

区切り時刻を過ぎた後にアプリを起動・復帰した場合、前日の進行中のことは自動的に「休んだ」として履歴に記録する。  
メイン画面は前日の「休んだ」状態を表示せず、すぐ今日の未設定状態に切り替える。

## 履歴シート

メイン画面のカレンダーアイコンから開く。

| 要素 | 内容 |
|------|------|
| 月カレンダー | 達成・休んだ・未記録を色で区別 |
| 日付選択 | タップするとその日の詳細を表示 |
| 日次詳細 | 選んだ日のことと結果を表示。過去の内容と結果は編集可能 |

### カレンダーの色定義

| 状態 | 表示 |
|------|------|
| 達成 | 塗りつぶし（黒） |
| 休んだ | アウトラインのみ |
| 未記録（未来・設定なし） | 何も表示しない |

---

## 設定シート

メイン画面の歯車アイコンから開く。

| 設定項目 | 内容 |
|----------|------|
| 通知 ON/OFF | 朝・夜の通知をまとめて切り替え |
| 朝の通知時間 | 「今日は何をする？」を送る時刻（デフォルト: 8:00） |
| 夜の通知時間 | 未設定時は「今からでもやること決めてみない？」、未完了時は「今日やること、どうだった？」を送る時刻（デフォルト: 21:00） |
| 日付の区切り時刻 | 新しい1日として扱う時刻（デフォルト: 4:00） |

通知許可は、ユーザーが通知 ON/OFF をONにしたタイミングで求める。  
朝の通知時刻、夜の通知時刻、日付の区切り時刻の間には制約を設けない。

---

## 画面遷移サマリー

```
起動
└── メイン（未設定）
    └── 入力・確定
        └── メイン（進行中）
            ├── 完了ボタン → メイン（完了）
            └── 区切り時刻を過ぎる → 前日を「休んだ」として履歴に記録 → メイン（未設定）

メイン（任意の状態）
├── カレンダーアイコン → 履歴シート
│   └── 日付タップ → 日次詳細（編集可）
└── 歯車アイコン → 設定シート
```
